# UUID 2026 Prototype based on dervoJS
The entire webapp is to be found inside the prototype directory.
dervoJS is currently not ready to be released, so this just contains the entire thing in src.

inside of prototype run yarn, followed by yarn build.  
You should then find a dist directory. serve this with a webserver of your choice, for example [This mess](https://github.com/ExtraTNT/MemeServer), if you find a worse server, let me know.
